# Security Policy

This policy sets the security update support policies and how to report the vulnerabilities of this application.

## Security Update Support

This application's secutity updates are supported only for the newest version.

| Version | Supported |
|:--------|:---------:|
| 1.0     | **No**    |
| 1.1     | **Yes**   |

## How to Report Vulnerabilities

Please feel free to report us via Private Reporting feature of the GitHub Repository.
Or you can report by sending an email to <b4151069@edu.kit.ac.jp>.

Please do not share the vulnerability information on Issues page to prevent the attackers find such information before we notice it.

Thank you very much for your cooperation.
